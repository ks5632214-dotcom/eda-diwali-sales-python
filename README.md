# 🪔 Diwali Sales Data Analysis (EDA) | Python

## 1. Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a Diwali sales dataset to uncover customer purchasing behavior, sales trends, and high-performing product categories.

The analysis transforms raw transactional data into **actionable business insights** that can help companies optimize marketing strategies during festive seasons.

## 2. Business Problem

Ecommerce platforms generate large volumes of sales data, but without proper analysis, it is difficult to identify:

* High-value customer segments
* Top-performing states and regions
* Profitable product categories
* Seasonal sales trends
* Customer purchasing patterns

This project addresses these challenges using data analysis and visualization.

## 3. Project Objectives

* Analyze customer demographics (age, gender, marital status)
* Identify top-selling product categories
* Determine state-wise sales performance
* Understand seasonal buying trends
* Generate insights for business decision-making

## 4. Tech Stack

* **Python** – Data analysis
* **Pandas** – Data manipulation
* **NumPy** – Numerical operations
* **Matplotlib & Seaborn** – Data visualization
* **Jupyter Notebook** – Development environment

## 5. Key Analysis Performed

* Data cleaning and preprocessing
* Handling missing values
* Exploratory Data Analysis (EDA)
* Groupby analysis (state, gender, age group)
* Visualization using bar charts, count plots, and heatmaps

## 6. Key Insights

* Married women aged **26–35 years** are the highest spenders
* Uttar Pradesh, Maharashtra, and Karnataka generate maximum sales
* Food, Clothing, and Electronics are top-selling categories
* Most buyers belong to IT, Healthcare, and Aviation sectors
* Purchasing behavior varies significantly across states and demographics

## 7. Dataset

* **File:** Diwali_Sales_Data.csv
* Contains customer demographics, product categories, purchase amounts, and location data
* Used to analyze festive season buying behavior
